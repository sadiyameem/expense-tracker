# Expense Tracker

# Description
- This is a simple web app that allows users to add, edit, delete, and filter their expenses while calculating the total amount spent.

# Features
  - Add expenses
  - Edit existing exoenses
  - Delete expenses
  - Filter expenses by category
  - Calculate total expenses by itself
  - Use of local storage
 
# Tools
- HTML
- CSS
- JavaScript
